## 0.0.5

First formally versioned DioramaOS release.

- Established Git repository
- Introduced semantic versioning
- Defined core domains:
  - Lights
  - Sounds
  - Animations
- Arduino Nano reference implementation
- DFPlayer Mini audio support
- PAM8302A amplifier
- DFPlayer BUSY-state monitoring
- Initial R2-D2 / C-3PO reference project
- Hardware documentation in Fritzing
